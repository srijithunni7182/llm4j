# X (Twitter) playbook

## Thread structure
Tweet 1 is the hook and must stand alone (it is what gets quoted and shared). Tweets 2–6 each deliver one idea, one line of white space between points. The last tweet summarises and gives a soft call to action (follow, bookmark, reply).

## Length and formatting
Each post has a 280-character limit for standard accounts. Short lines, plain language, no hashtag spam — one or two relevant hashtags at most, usually in the last tweet. Numbered tweets (1/, 2/) help readers track progress.

## Standalone post
Alongside a thread, write one punchy standalone post that works without context — a sharp opinion or a surprising, sourced fact.

## Engagement prompts
End with a question people can answer in a few words. Replies within the first hour matter, so the creator should plan to respond.
