# Review Checklist
- Does it meet every acceptance criterion in the PRD? Name any that are missing.
- Correctness first: edge cases, error handling, concurrency, security (inputs, secrets, permissions).
- Is it tested at the right level, and do the tests fail if the behaviour breaks?
- Readability: clear names, small functions, no dead code, comments explain why rather than what.
- Give each finding a severity (blocker, major, minor) and a concrete fix.
