# Contributing to Gemini ReAct Java

We love your input! We want to make contributing to `gemini-react-java` as easy and transparent as possible, whether it's:

- Reporting a bug
- Discussing the current state of the code
- Submitting a fix
- Proposing new features
- Becoming a maintainer

## We Develop with Github

We use github to host code, to track issues and feature requests, and to accept pull requests.

## Report bugs using Github's [issues](https://github.com/srijithunni7182/llm4j/issues)

We use GitHub issues to track public bugs. Report a bug by [opening a new issue](https://github.com/srijithunni7182/llm4j/issues/new); it's that easy!

**Great Bug Reports** tend to have:

- A quick summary and/or background
- Steps to reproduce
  - Be specific!
  - Give sample code if you can.
- What you expected would happen
- What actually happened
- Notes (possibly including why you think this might be happening, or stuff you tried that didn't work)

## Code Contribution Process

1. **Fork the repo** and create your branch from `main`.
2. **Clone the repo** locally.
3. **Run Tests**: Ensure all tests pass. We pride ourselves on 100% integration test coverage.

    ```bash
    mvn clean install
    ```

4. **Make your changes**: Add comprehensive tests for any new feature.
5. **Format your code**: Follow standard Java conventions.
6. **Submit a Pull Request**: describing your changes.
