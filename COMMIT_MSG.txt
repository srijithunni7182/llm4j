feat: Add Agent Personas, RAG Support, and Knowledge Graphs

Implemented three major enhancements to the llm4j library:

## 1. Agent Personas
- Created AgentPersona class with builder pattern for configurable behavioral characteristics
- Added PersonaLibrary with 8 pre-built personas (Technical Analyst, Creative Writer, Customer Support, etc.)
- Integrated persona support into ReActAgent via builder pattern
- Personas modify system prompts to guide agent behavior

New files:
- src/main/java/io/github/llm4j/agent/persona/AgentPersona.java
- src/main/java/io/github/llm4j/agent/persona/PersonaLibrary.java
- src/test/java/io/github/llm4j/agent/persona/AgentPersonaTest.java (8 tests)
- src/test/java/io/github/llm4j/agent/persona/PersonaLibraryTest.java (9 tests)

## 2. RAG (Retrieval-Augmented Generation)
- Implemented document processing with chunking strategies
- Created GeminiEmbeddingProvider using text-embedding-004 (768 dimensions)
- Built InMemoryVectorStore with cosine similarity search
- Developed RAGAgent for context-aware responses

New files:
- src/main/java/io/github/llm4j/agent/rag/document/* (Document, DocumentChunk, ChunkingStrategy, FixedSizeChunkingStrategy)
- src/main/java/io/github/llm4j/agent/rag/embedding/* (EmbeddingProvider, GeminiEmbeddingProvider)
- src/main/java/io/github/llm4j/agent/rag/store/* (VectorStore, InMemoryVectorStore)
- src/main/java/io/github/llm4j/agent/rag/RAGAgent.java
- src/test/java/io/github/llm4j/agent/rag/DocumentChunkingTest.java (7 tests)
- src/test/java/io/github/llm4j/agent/rag/InMemoryVectorStoreTest.java (8 tests)
