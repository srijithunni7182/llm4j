# LO01: The script is scheduled but has no <script>.inspect rules file

- **Lens:** Observability
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each script
- **Since:** core 1.5.0

Why it matters: A scheduled run is watched against thresholds (looping, failing tools, a nearly full context). With no rules file the defaults apply and nothing records a decision about this workflow.

What to do: Write a <script>.inspect file beside the script with the thresholds this workflow should be watched against.

## When it fires

`isScheduled is true and hasInspectRules is false`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LO01 = off` in `review.properties` turns the rule off, and `LO01.severity = low` changes how loud it is.
