# LA18: A steerable agent is an input channel

- **Lens:** Security
- **Severity:** varies
- **From:** audit

A person's text reaches this agent while it works. It is checked by its guard and recorded, but it is an input channel like any other.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA18 = off` in `review.properties` turns the rule off, and `LA18.severity = low` changes how loud it is.
