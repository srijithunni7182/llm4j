# LG01: Model `id` is not a model this library knows, and is close to `nearest`

- **Lens:** Model governance (off until asked for)
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each model
- **Since:** core 1.6.0

The library ships a short list of models it has checked. A name that is not on it is not wrong (there are many models), but a name that is one or two letters away from a listed model is probably a typo.

Why it matters: A misspelt model name fails at run time, or silently calls a different model than the one intended.

What to do: Check the spelling: did you mean {nearest}?

This rule belongs to an optional lens, off until you turn it on (--lens +governance).

## When it fires

`known is false and nearest is not `

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LG01 = off` in `review.properties` turns the rule off, and `LG01.severity = low` changes how loud it is.
