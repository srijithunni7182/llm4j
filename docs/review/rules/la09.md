# LA09: Long-term memory on an agent that reads untrusted content

- **Lens:** Security
- **Severity:** varies
- **From:** audit

What an untrusted page writes into memory is read back later as if it were a fact.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA09 = off` in `review.properties` turns the rule off, and `LA09.severity = low` changes how loud it is.
