# LY05: Classifier `name` has no confidence rule, so doubtful answers are routed as if certain

- **Lens:** Privacy and compliance
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each classifier
- **Since:** core 1.5.0

Why it matters: A classifier always answers. Without a confidence threshold a guess and a sure answer take the same path.

What to do: Add confidence at least 0.8 else escalate to the classifier.

## When it fires

`hasConfidenceRule is false`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LY05 = off` in `review.properties` turns the rule off, and `LY05.severity = low` changes how loud it is.
