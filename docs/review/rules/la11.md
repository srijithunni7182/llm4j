# LA11: A rewind that repeats side effects

- **Lens:** Security
- **Severity:** varies
- **From:** audit

Going back crosses effects that already happened. Choose what to do about them.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA11 = off` in `review.properties` turns the rule off, and `LA11.severity = low` changes how loud it is.
