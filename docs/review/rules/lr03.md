# LR03: `label` has no maximum number of rounds

- **Lens:** Reliability
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.0.0

Bound every loop. With max N the runtime stops after N rounds and runs the on_exhausted block, so the cost of the loop has an upper limit and the run cannot spin unnoticed.

Why it matters: A loop that only stops when its condition becomes true can run for ever if the condition never does, and every round may call a model.

What to do: Add a maximum, such as max 5, and say what happens when it is reached.

## When it fires

`kind is loop and hasMax is false`

## Fix

`weave review --fix` applies: Add a maximum number of rounds.

## Options

`weave review --assist` offers these, and you choose and give the values.

- **max-rounds**: Stop after a number of rounds. The loop ends after that many rounds even if its condition still holds, so its cost has an upper limit. Asks: Most rounds the loop may run (default `5`).

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LR03 = off` in `review.properties` turns the rule off, and `LR03.severity = low` changes how loud it is.
