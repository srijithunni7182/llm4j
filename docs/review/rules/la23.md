# LA23: An agent reads a file chosen at run time

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An agent sent a picture, recording or document whose file name is filled in at run time reads untrusted content: it can carry instructions that masking cannot see. Name the file in the script where you can.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA23 = off` in `review.properties` turns the rule off, and `LA23.severity = low` changes how loud it is.
