# LP01: Agent `name` has a variable written into its system prompt

- **Lens:** Prompts
- **Severity:** medium, raised to high when hasTools is true
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.2.0

The system prompt is the agent's rules. Anything interpolated into it by name can carry instructions of its own. Put variable content in the task text of the delegate, where it is data to work on. The severity is raised for an agent with tools, because there the injected instruction can act.

Why it matters: A value filled into the system prompt is read as an instruction. If it comes from a person, a tool or an input, it can rewrite the agent's rules.

What to do: Keep the system prompt fixed and pass the value in the task text, marked as data.

## When it fires

`systemInterpolates is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LP01 = off` in `review.properties` turns the rule off, and `LP01.severity = low` changes how loud it is.
