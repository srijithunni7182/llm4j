# LY06: Agent `name`'s prompt holds an email address or phone number that looks real

- **Lens:** Privacy and compliance
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.5.0

Why it matters: A real person's contact details in a prompt are committed with the script and sent to the provider on every call.

What to do: Replace it with a placeholder such as jane@example.com.

## When it fires

`promptHasPersonalData is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LY06 = off` in `review.properties` turns the rule off, and `LY06.severity = low` changes how loud it is.
