# LP05: Agent `name` acts or decides but its prompt does not say what to do when unsure

- **Lens:** Prompts
- **Severity:** info
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.5.0
- **Heuristic:** yes, it guesses from names or wording, so it runs only with `heuristics = on` or when named in `review.properties`.

This rule guesses from the wording of the prompt, so it runs only with heuristics on.

Why it matters: An agent that is never told it may decline will guess, and a guess that sends or decides has consequences.

What to do: Add a sentence: if you are not sure, or the request is out of scope, say so and ask a person.

This rule guesses from names or text, so it runs only when heuristics are on or the rule is named in review.properties.

## When it fires

`promptSaysWhenUnsure is false and (feedsDecision is true or hasEffects is true)`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LP05 = off` in `review.properties` turns the rule off, and `LP05.severity = low` changes how loud it is.
