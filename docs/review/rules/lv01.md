# LV01: A name is used that is not defined

- **Lens:** Validity
- **Severity:** varies
- **From:** validator

An agent, tool, task or workflow is named that the script does not define, so the step cannot run. An error from weave check is a high finding and a warning a low one. What to do: Use a name that is defined (the message lists them), or define the missing one.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV01 = off` in `review.properties` turns the rule off, and `LV01.severity = low` changes how loud it is.
