# LB01: `label` can write or send inside a repeat with no limit on calls

- **Lens:** Blast radius (off until asked for)
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.6.0

Looks for a step that acts on the world (its agent has a tool that writes or sends) inside a for each, or inside a loop with no max, when no budget with a calls limit applies to it.

Why it matters: A for each over a long list, or a loop with no maximum, can cause as many effects as it has turns, and nothing in the script stops it.

What to do: Add a budget with a calls limit to the step, the loop or the script, or give the loop a max.

This rule belongs to an optional lens, off until you turn it on (--lens +blast-radius).

## When it fires

`kind is delegate and inUnboundedRepeat is true and agent.hasEffects is true and effectCapped is false`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LB01 = off` in `review.properties` turns the rule off, and `LB01.severity = low` changes how loud it is.
