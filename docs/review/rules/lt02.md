# LT02: An agent or classifier is scripted by no test

- **Lens:** Testability (off until asked for)
- **Severity:** low
- **From:** testability

When tests exist, each agent and classifier should be scripted (models:) by at least one, or its behaviour in the workflow is never exercised. What to do: add a case that names it.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LT02 = off` in `review.properties` turns the rule off, and `LT02.severity = low` changes how loud it is.
