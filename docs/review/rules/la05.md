# LA05: allow_private or allow_http

- **Lens:** Security
- **Severity:** varies
- **From:** audit

A tool is allowed to reach private network addresses or use plain HTTP. Keep these off unless the tool needs them.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA05 = off` in `review.properties` turns the rule off, and `LA05.severity = low` changes how loud it is.
