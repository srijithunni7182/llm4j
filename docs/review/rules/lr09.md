# LR09: `label` has branches that bind the same variable

- **Lens:** Reliability
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.2.0

Why it matters: Branches of a parallel round finish in any order, so which answer ends up in the shared variable changes from run to run.

What to do: Give each branch its own variable name.

## When it fires

`kind is parallel and writesSameVariableAsSibling is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LR09 = off` in `review.properties` turns the rule off, and `LR09.severity = low` changes how loud it is.
