# LA07: Email recipients by pattern, or mail without TLS

- **Lens:** Security
- **Severity:** varies
- **From:** audit

Recipients chosen by a pattern, or mail sent without TLS, widens who can be written to or read in transit.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA07 = off` in `review.properties` turns the rule off, and `LA07.severity = low` changes how loud it is.
