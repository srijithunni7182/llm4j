# LD04: `label` retries a call to your own Java code that writes or sends, and nothing records that it already happened

- **Lens:** Durability
- **Severity:** high
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.5.0

Why it matters: A retry runs the call again. Your own Java tools are not journaled, so a call that sent the mail but timed out is sent again.

What to do: Make the tool idempotent and say so, switch to a built-in tool kind that is journaled, or remove the retry.

## When it fires

`kind is delegate and retry is true and some of agent.tools where (kind is class and reachKnown is true and reach is one of [writes, sends] and idempotentDeclared is false)`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LD04 = off` in `review.properties` turns the rule off, and `LD04.severity = low` changes how loud it is.
