# LC04: The budget is below what a normal run costs

- **Lens:** Cost and performance
- **Severity:** medium
- **From:** cost

A budget stops or pauses a run when it is spent. If the budget is smaller than the typical cost of the workflow, most runs are cut off. The estimate is from the script alone (weave review --explain cost). What to do: raise the budget above the typical cost or make the workflow cheaper.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LC04 = off` in `review.properties` turns the rule off, and `LC04.severity = low` changes how loud it is.
