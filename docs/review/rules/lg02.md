# LG02: Model `id` is listed as deprecated by this project

- **Lens:** Model governance (off until asked for)
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each model
- **Since:** core 1.6.0

The library cannot know which models are about to be retired, so the project says: list them in review.properties as data.deprecated-models = model-a, model-b. Without that setting the rule is not evaluated, and the report says so.

Why it matters: A deprecated model is retired on a date the vendor sets; after that the agent fails or is moved to another model without a change in the repository.

What to do: Move the agent to the model that replaces it, and test it.

This rule belongs to an optional lens, off until you turn it on (--lens +governance).

## When it fires

`deprecated is true`

Not evaluated unless the project declares: `data.deprecated-models` in `review.properties`.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LG02 = off` in `review.properties` turns the rule off, and `LG02.severity = low` changes how loud it is.
