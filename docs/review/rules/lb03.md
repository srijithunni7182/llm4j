# LB03: A scheduled workflow has no limit on what it spends in a day

- **Lens:** Blast radius (off until asked for)
- **Severity:** medium
- **From:** posture

A schedule repeats a workflow without anyone looking. Without a budget per day, a mistake repeats at full price until someone notices. With blast.max-daily-cost and a price table, the worst case of one run times the runs per day is also compared with it. What to do: add budget { tokens: N per day }.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LB03 = off` in `review.properties` turns the rule off, and `LB03.severity = low` changes how loud it is.
