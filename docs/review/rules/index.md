# Review rules

Generated by `weave rules docs core`. Every rule `weave review` applies, grouped by lens. A rule marked *(off)* belongs to a lens that is off until you ask for it (`--lens +NAME`, or `--lens all`). See [how to write a rule](../WRITING_RULES.md).

| Rule | Severity | What it looks for |
|---|---|---|
| [LA01](la01.md) | varies | One agent has the lethal trifecta |
| [LA02](la02.md) | varies | Effects with no approval |
| [LA03](la03.md) | varies | No run budget |
| [LA04](la04.md) | varies | Private data with no PII guard |
| [LA05](la05.md) | varies | allow_private or allow_http |
| [LA06](la06.md) | varies | A shell tool that can run interpreters |
| [LA07](la07.md) | varies | Email recipients by pattern, or mail without TLS |
| [LA08](la08.md) | varies | Content fetched from the network |
| [LA09](la09.md) | varies | Long-term memory on an agent that reads untrusted content |

| [LA11](la11.md) | varies | A rewind that repeats side effects |

## Privacy and compliance

|---|---|---|

## Durability

| Rule | Severity | What it looks for |
|---|---|---|
| [LD01](ld01.md) | high | The script pauses for a person or a timer and the project says journal = none |
| [LD02](ld02.md) | high | Tool `name` is your own Java: a resumed run can repeat what it does |
| [LD04](ld04.md) | high | `label` retries a call to your own Java code that writes or sends, and nothing records that it already happened |

## Cost and performance

| Rule | Severity | What it looks for |
|---|---|---|
| [LC01](lc01.md) | medium | Agent `name` looks like a classifier but runs on `model.id`, one of your most expensive models |
| [LC02](lc02.md) | low | `label` repeats with nothing bounding the conversation, so each round re-sends everything said so far |
| [LC03](lc03.md) | low | `label` sends the same work to several agents and one of them runs on one of your most expensive models |
| [LC04](lc04.md) | medium | The budget is below what a normal run costs |
| [LC05](lc05.md) | info | One step is most of a workflow's cost |
| [LC06](lc06.md) | low | A retried step can be expensive in the worst case |
| [LC07](lc07.md) | info | `label` asks a model for something a program could do |
| [LC08](lc08.md) | low | `label` does not use the answer of the step before it and could run beside it (saves about `parallelSavingSeconds` s) |
| [LC09](lc09.md) | medium | The longest allowed run takes longer than the limit |
| [LC10](lc10.md) | medium | An interactive workflow is slow or waits |
