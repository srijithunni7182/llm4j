# LV06: A statement can never run

- **Lens:** Validity
- **Severity:** varies
- **From:** validator

Nothing can reach this statement, so it does nothing. An error from weave check is a high finding and a warning a low one. What to do: Delete it, or fix the condition that keeps it from running.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV06 = off` in `review.properties` turns the rule off, and `LV06.severity = low` changes how loud it is.
