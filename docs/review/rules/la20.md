# LA20: A grounded agent reads the open web

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An agent with grounding: web counts as reading untrusted content for the trifecta, whatever allow: says.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA20 = off` in `review.properties` turns the rule off, and `LA20.severity = low` changes how loud it is.
