# LY04: Agent `name` feeds a decision but has no bias guard

- **Lens:** Privacy and compliance
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.5.0

Why it matters: When an agent's answer decides something, a bias guard is where unfair patterns are noticed or stopped.

What to do: Add guard { bias: warn } (or block) to the agent.

## When it fires

`feedsDecision is true and guardBias is none`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LY04 = off` in `review.properties` turns the rule off, and `LY04.severity = low` changes how loud it is.
