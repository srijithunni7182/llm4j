# LM03: Workflow `name` is large: `stepCount` statements, nested `maxDepth` deep

- **Lens:** Maintainability (off until asked for)
- **Severity:** info
- **From:** the core rule pack
- **Applies to:** each workflow
- **Since:** core 1.6.0

More than data.workflow.max-steps statements (default 60) or nesting deeper than data.workflow.max-depth (default 5) is the point where a workflow is usually better split.

Why it matters: A workflow with many statements or deep nesting is hard to read, test and change safely.

What to do: Split it into smaller workflows and join them with call.

This rule belongs to an optional lens, off until you turn it on (--lens +maintainability).

## When it fires

`stepCount > the setting data.workflow.max-steps or maxDepth > the setting data.workflow.max-depth`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LM03 = off` in `review.properties` turns the rule off, and `LM03.severity = low` changes how loud it is.
