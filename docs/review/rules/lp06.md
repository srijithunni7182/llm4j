# LP06: Agent `name`'s prompt nearly repeats `nearDuplicateOf`'s

- **Lens:** Prompts
- **Severity:** info
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.2.0

Why it matters: Two prompts that say the same thing drift apart when only one is edited.

What to do: Move the shared text into a persona both agents use.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LP06 = off` in `review.properties` turns the rule off, and `LP06.severity = low` changes how loud it is.
