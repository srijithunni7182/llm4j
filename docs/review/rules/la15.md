# LA15: A tool whose reach is its author's declaration

- **Lens:** Security
- **Severity:** varies
- **From:** audit

The audit believes the declared reach. Read the tool's code once to confirm it.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA15 = off` in `review.properties` turns the rule off, and `LA15.severity = low` changes how loud it is.
