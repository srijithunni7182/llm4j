# LH04: `label` takes a free-text answer that a condition then compares

- **Lens:** Human oversight (off until asked for)
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.6.0

Looks for a human_prompt whose variable is used in a later condition. The free-text answer is matched exactly, so only the spelling the author thought of works.

Why it matters: People type 'Yes', 'yes ', 'y' and 'ok'. A comparison against one spelling takes the others for no.

What to do: Ask a question with a fixed set of answers (a decide, or a prompt that tells the person to answer exactly yes or no) and compare against that.

This rule belongs to an optional lens, off until you turn it on (--lens +oversight).

## When it fires

`kind is human_prompt and answerCompared is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LH04 = off` in `review.properties` turns the rule off, and `LH04.severity = low` changes how loud it is.
