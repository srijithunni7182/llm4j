# LV07: Something is defined twice

- **Lens:** Validity
- **Severity:** varies
- **From:** validator

Two definitions share a name, so one of them silently wins or the script is ambiguous. An error from weave check is a high finding and a warning a low one. What to do: Rename or remove one of them.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV07 = off` in `review.properties` turns the rule off, and `LV07.severity = low` changes how loud it is.
