# LC07: `label` asks a model for something a program could do

- **Lens:** Cost and performance
- **Severity:** info
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.5.0
- **Heuristic:** yes, it guesses from names or wording, so it runs only with `heuristics = on` or when named in `review.properties`.

This rule guesses from the wording of the prompt (calculate, validate the format, check against the table …), so it runs only with heuristics on.

Why it matters: Arithmetic, format checks and table lookups are exact in code and cost nothing per call; a model does them at a price and can get them wrong.

What to do: Do it in a run task and keep the model for what needs judgement.

This rule guesses from names or text, so it runs only when heuristics are on or the rule is named in review.properties.

## When it fires

`kind is delegate and payloadSaysDeterministic is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LC07 = off` in `review.properties` turns the rule off, and `LC07.severity = low` changes how loud it is.
