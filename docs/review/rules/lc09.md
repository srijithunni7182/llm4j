# LC09: The longest allowed run takes longer than the limit

- **Lens:** Cost and performance
- **Severity:** medium
- **From:** cost

When the project declares cost.latency.limit (seconds), the worst-case time of each workflow, from the latency assumptions and without waits for people, is compared with it. What to do: parallelise independent steps, lower retries or timeouts, or use a faster model.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LC09 = off` in `review.properties` turns the rule off, and `LC09.severity = low` changes how loud it is.
