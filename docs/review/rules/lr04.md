# LR04: `label` waits for a person with no timeout in a scheduled workflow

- **Lens:** Reliability
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.2.0

Why it matters: A scheduled workflow runs when nobody is watching. A question with no timeout holds the run until someone happens to answer, and overlapping runs may pile up behind it.

What to do: Add a timeout, or an escalation, to the question.

## When it fires

`kind is human_prompt and timeout is false and workflow.isScheduled is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LR04 = off` in `review.properties` turns the rule off, and `LR04.severity = low` changes how loud it is.
