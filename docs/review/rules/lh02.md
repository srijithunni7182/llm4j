# LH02: Agent `name` asks a person to approve a tool that only reads

- **Lens:** Human oversight (off until asked for)
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.6.0

Approval is for tools that write or send. Asking for it on a tool whose reach is declared as none or reads adds friction without protection.

Why it matters: When people are asked to approve things that cannot do harm, they learn to click yes without reading, and the approvals that matter get the same click.

What to do: Remove the approval from the read-only tool, or declare that its reach is wider if it is.

This rule belongs to an optional lens, off until you turn it on (--lens +oversight).

## When it fires

`approvesLowReachTool is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LH02 = off` in `review.properties` turns the rule off, and `LH02.severity = low` changes how loud it is.
