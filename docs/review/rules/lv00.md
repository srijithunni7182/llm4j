# LV00: A problem weave check reports that has no rule of its own yet

- **Lens:** Validity
- **Severity:** varies
- **From:** validator

weave check found something wrong or doubtful in the script that is not one of the classes above. An error is a high finding and a warning a low one. Run weave check for the full message.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV00 = off` in `review.properties` turns the rule off, and `LV00.severity = low` changes how loud it is.
