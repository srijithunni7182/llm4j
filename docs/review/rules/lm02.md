# LM02: Agent `name` has a prompt of `inlinePromptLines` lines written inside the script

- **Lens:** Maintainability (off until asked for)
- **Severity:** info
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.6.0

Prompts that are more than data.inline.max-lines lines (default 12) are better kept as files in a prompts folder, where they can be versioned, diffed and pinned.

Why it matters: A long prompt in the script buries the workflow's shape, cannot be versioned or reviewed on its own, and makes the script hard to read.

What to do: Move the prompt to prompts/<agent>.md and refer to it with prompt: "<agent>".

This rule belongs to an optional lens, off until you turn it on (--lens +maintainability).

## When it fires

`inlinePromptLines > the setting data.inline.max-lines`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LM02 = off` in `review.properties` turns the rule off, and `LM02.severity = low` changes how loud it is.
