# LC01: Agent `name` looks like a classifier but runs on `model.id`, one of your most expensive models

- **Lens:** Cost and performance
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.1.0

This rule needs to know which models you consider expensive, so it only runs when data.top-models lists them in review.properties (for example data.top-models = claude-opus-5-5, gpt-5). It looks for agents that only choose: no tools, an output_schema, and a prompt of ten lines or fewer. Check the quality with weave eval before and after switching.

Why it matters: An agent with no tools, a structured answer and a short prompt is picking from a few options. A smaller model usually does that as well for a fraction of the price, and it is paid for on every run.

What to do: Try a smaller model for this agent, or an intentclassifier, and keep the big model for the steps that need it.

## When it fires

`model.id is one of the setting data.top-models and hasTools is false and hasSchema is true and inlinePromptLines <= 10 and stepCount >= 1`

Not evaluated unless the project declares: `data.top-models` in `review.properties`.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LC01 = off` in `review.properties` turns the rule off, and `LC01.severity = low` changes how loud it is.
