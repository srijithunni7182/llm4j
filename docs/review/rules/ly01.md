# LY01: `label` sends a value that looks personal to the model and the agent has no guard that masks it

- **Lens:** Privacy and compliance
- **Severity:** medium, raised to high when agent.hasEffects is true
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.5.0

The prompt fills in a value whose name says it is personal (email, phone, address, dob, ssn, card, or a first, last or full name) or that data.personal in review.properties lists. The check goes by names, not by looking at the data, so name your fields plainly or list them.

Why it matters: An email address, phone number, address or a person's name filled into a prompt goes to the model provider as it is. A guard with pii: mask removes it first.

What to do: Add guard { pii: mask } to the agent, or leave the personal value out of the prompt.

## When it fires

`kind is delegate and payloadMentionsPersonal is true and agent.guardPii is one of [none, warn]`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LY01 = off` in `review.properties` turns the rule off, and `LY01.severity = low` changes how loud it is.
