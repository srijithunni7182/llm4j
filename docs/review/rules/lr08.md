# LR08: The script is scheduled but declares no rate_limits

- **Lens:** Reliability
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each script
- **Since:** core 1.2.0

Why it matters: An unattended run that hits a provider limit has no rule for waiting or giving up, so it fails or retries without bound.

What to do: Add a rate_limits block saying whether to suspend, wait or fail.

## When it fires

`isScheduled is true and hasRateLimits is false`

## Fix

`weave review --fix` applies: Add a rate_limits block.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LR08 = off` in `review.properties` turns the rule off, and `LR08.severity = low` changes how loud it is.
