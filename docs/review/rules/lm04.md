# LM04: Agent `name` is the same as agent `identicalTo` under another name

- **Lens:** Maintainability (off until asked for)
- **Severity:** info
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.6.0

Compares agents by model, prompt, tools and approvals. Two workflow bodies that are identical apart from names are not compared yet.

Why it matters: Two agents with the same model, prompt, tools and approvals are one agent. Keeping both means every change has to be made twice.

What to do: Use one agent in both places.

This rule belongs to an optional lens, off until you turn it on (--lens +maintainability).

## When it fires

`identicalTo is not `

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LM04 = off` in `review.properties` turns the rule off, and `LM04.severity = low` changes how loud it is.
