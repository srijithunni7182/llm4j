# LT06: An agent has no golden dataset (heuristic)

- **Lens:** Testability (off until asked for)
- **Severity:** low
- **From:** testability

weave eval compares an agent's answers with a golden dataset in eval/golden/<agent>.yaml. This rule goes by that file name, so it runs only with heuristics on or when named. What to do: weave eval --init.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LT06 = off` in `review.properties` turns the rule off, and `LT06.severity = low` changes how loud it is.
