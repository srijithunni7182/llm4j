# LV05: A human's answer changes nothing

- **Lens:** Validity
- **Severity:** varies
- **From:** validator

A person is asked, but the answer is never read, so the workflow does the same whatever they say. An error from weave check is a high finding and a warning a low one. What to do: Use the answer in a condition or step, or remove the question.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV05 = off` in `review.properties` turns the rule off, and `LV05.severity = low` changes how loud it is.
