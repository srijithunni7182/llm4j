# LV09: A setting is wrong, missing or has no effect

- **Lens:** Validity
- **Severity:** varies
- **From:** validator

An option has a value the engine does not accept, a required option is missing, or two options contradict each other. An error from weave check is a high finding and a warning a low one. What to do: Change the setting as the message says; weave check explains each one.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV09 = off` in `review.properties` turns the rule off, and `LV09.severity = low` changes how loud it is.
