# LA26: A channel answers with no person

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An agent_channel with audience automatic answers a party from outside without a person looking. High when a remote agent uses it, because that agent can ask for authorization.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA26 = off` in `review.properties` turns the rule off, and `LA26.severity = low` changes how loud it is.
