# LA19: A classifier sends its state to a hosted service

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An intentclassify step sends the state of the run to a hosted service. Check which fields and whether pii: masks them.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA19 = off` in `review.properties` turns the rule off, and `LA19.severity = low` changes how loud it is.
