# LV02: A file, secret or environment value is missing

- **Lens:** Validity
- **Severity:** varies
- **From:** validator

A prompt file, secret, environment variable or source the script depends on is not there, so it fails before it starts or at the first use. An error from weave check is a high finding and a warning a low one. What to do: Create the file, set the secret or variable, or point the script at the right one (weave secret).

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV02 = off` in `review.properties` turns the rule off, and `LV02.severity = low` changes how loud it is.
