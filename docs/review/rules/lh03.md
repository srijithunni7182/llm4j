# LH03: A run can put too many questions to a person

- **Lens:** Human oversight (off until asked for)
- **Severity:** medium
- **From:** posture

People answer the first questions with care and the tenth with a click. When the worst case of one run is more than oversight.max-questions (default 10) human_prompt and decide questions, the answers stop meaning anything. What to do: ask fewer, or ask once about the whole batch.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LH03 = off` in `review.properties` turns the rule off, and `LH03.severity = low` changes how loud it is.
