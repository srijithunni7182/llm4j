# LV08: A suppression has no reason

- **Lens:** Validity
- **Severity:** medium
- **From:** review.properties

A line such as LR05.suppress = Router in review.properties sets a finding aside but gives no reason, so it hides nothing and is reported itself. A suppression nobody explained cannot be reviewed later. What to do: add the reason in quotes after the place.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV08 = off` in `review.properties` turns the rule off, and `LV08.severity = low` changes how loud it is.
