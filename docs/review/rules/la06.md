# LA06: A shell tool that can run interpreters

- **Lens:** Security
- **Severity:** varies
- **From:** audit

A shell tool whose allow-list includes interpreters can run anything. Narrow the allow-list to the commands needed.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA06 = off` in `review.properties` turns the rule off, and `LA06.severity = low` changes how loud it is.
