# LA17: A tool that acts as the person running the workflow

- **Lens:** Security
- **Severity:** varies
- **From:** audit

The tool uses the invoker's credentials. Put approve: on it so nothing is done in their name unseen.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA17 = off` in `review.properties` turns the rule off, and `LA17.severity = low` changes how loud it is.
