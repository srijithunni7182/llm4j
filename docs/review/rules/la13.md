# LA13: Indexed documents become instructions-in-waiting

- **Lens:** Security
- **Severity:** varies
- **From:** audit

Whatever is in an indexed document is shown to the model later, so it must be trusted.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA13 = off` in `review.properties` turns the rule off, and `LA13.severity = low` changes how loud it is.
