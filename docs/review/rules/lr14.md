# LR14: `label` is judged by the same model that wrote the text (`checkedAgent`)

- **Lens:** Reliability
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 6.2.0

Fires on a check whose evaluator is declared with the same model as the agent that wrote the text it checks. It is the second half of rule LR12 in the design (a separate id, because a rule is about one kind of step). Only the declared models are compared.

Why it matters: A model judging its own kind of text shares its blind spots, so a violation it wrote is less likely to be seen.

What to do: Give the evaluator a model from another provider, or at least another model than agent {checkedAgent}'s.

## When it fires

`checkedByOwnModel is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LR14 = off` in `review.properties` turns the rule off, and `LR14.severity = low` changes how loud it is.
