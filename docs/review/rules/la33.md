# LA33: A sandbox reaches the network

- **Lens:** Security
- **Severity:** varies
- **From:** audit

A sandbox with network: allow reaches the listed hosts through the egress proxy and nothing else (info; a wildcard host is called out as wide); with network: open it reaches any host (medium).

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA33 = off` in `review.properties` turns the rule off, and `LA33.severity = low` changes how loud it is.
