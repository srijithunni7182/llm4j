# LT04: Retries and failure paths are never tested

- **Lens:** Testability (off until asked for)
- **Severity:** medium
- **From:** testability

A script with retry, on_failure, rewind or on_stopped has paths that run only when something fails. When tests exist and none injects a failure (fail:), those paths are untested. What to do: add a case with a fail: entry.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LT04 = off` in `review.properties` turns the rule off, and `LT04.severity = low` changes how loud it is.
