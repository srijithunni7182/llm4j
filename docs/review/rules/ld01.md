# LD01: The script pauses for a person or a timer and the project says journal = none

- **Lens:** Durability
- **Severity:** high
- **From:** the core rule pack
- **Applies to:** each script
- **Since:** core 1.5.0

The script asks a person, sleeps, or waits for approval. Those pauses are only safe when the run is journaled, so that a resumed run continues where it stopped and does not repeat what it already did. This rule needs the project to say what it uses (journal = none, file or jdbc in review.properties); until then it is reported as not evaluated rather than guessed.

Why it matters: A pause outlives the process that started it. Without a journal a restart forgets where the run was, so the person's answer or the timer has nothing to resume.

What to do: Run with a journal (--journal DIR) and set journal = file in review.properties.

## When it fires

`usesPausing is true and setting.journal is none`

Not evaluated unless the project declares: `journal` in `review.properties`.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LD01 = off` in `review.properties` turns the rule off, and `LD01.severity = low` changes how loud it is.
