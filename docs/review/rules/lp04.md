# LP04: Agent `name`'s prompt holds something shaped like a key or password

- **Lens:** Prompts
- **Severity:** high
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.2.0

Why it matters: A key written in a prompt is committed with the script and sent to the model provider on every call.

What to do: Remove it, rotate the key, and read it from env.NAME or the secret store where it is needed.

## When it fires

`promptHasSecret is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LP04 = off` in `review.properties` turns the rule off, and `LP04.severity = low` changes how loud it is.
