# LV04: The script reads something the answer does not have

- **Lens:** Validity
- **Severity:** varies
- **From:** validator

A condition or placeholder reads a field the answer does not have, or the answer is not in the shape it is read as, so the step misbehaves. An error from weave check is a high finding and a warning a low one. What to do: Use a field the answer has, or change the output schema so it has this one.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV04 = off` in `review.properties` turns the rule off, and `LV04.severity = low` changes how loud it is.
