# LA25: Data leaves to a remote agent

- **Lens:** Security
- **Severity:** varies
- **From:** audit

A delegate to a remote agent sends text and files to another organisation. Nothing in the script masks personal data first unless an agent of the workflow has a pii guard. Medium when the workflow reaches private data and nothing masks it.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA25 = off` in `review.properties` turns the rule off, and `LA25.severity = low` changes how loud it is.
