# LA32: A workflow reaches a process it started

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An http tool with reaches: calls the program a sandbox serves, on 127.0.0.1 and that program's one port, only while its lease lives. Names the tool and the sandbox that owns the port. Info: the grant is exactly one port, never a loopback switch.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA32 = off` in `review.properties` turns the rule off, and `LA32.severity = low` changes how loud it is.
