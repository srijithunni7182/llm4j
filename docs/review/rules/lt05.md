# LT05: A person's answer is never scripted

- **Lens:** Testability (off until asked for)
- **Severity:** low
- **From:** testability

A script that asks a person (human_prompt, decide, an approval) needs a test that supplies answers (humans:), or the branches after the question are untested. What to do: add a case with humans:.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LT05 = off` in `review.properties` turns the rule off, and `LT05.severity = low` changes how loud it is.
