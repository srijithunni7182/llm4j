# LA04: Private data with no PII guard

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An agent can reach private data and has no guard { pii: ... }. Mask or block personal data before it reaches a model or a log.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA04 = off` in `review.properties` turns the rule off, and `LA04.severity = low` changes how loud it is.
