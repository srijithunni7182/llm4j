# LM05: The number `repeatedThreshold` is compared against in `repeatedThresholdCount` conditions

- **Lens:** Maintainability (off until asked for)
- **Severity:** info
- **From:** the core rule pack
- **Applies to:** each script
- **Since:** core 1.6.0

Counts the numbers conditions compare against. When one appears data.threshold.repeats times (default 4) or more, it is probably one decision written several times.

Why it matters: A threshold written in many places has to be changed in all of them, and one is always missed.

What to do: Keep the number in one place: a set variable, or a workflow input.

This rule belongs to an optional lens, off until you turn it on (--lens +maintainability).

## When it fires

`repeatedThresholdCount >= the setting data.threshold.repeats`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LM05 = off` in `review.properties` turns the rule off, and `LM05.severity = low` changes how loud it is.
