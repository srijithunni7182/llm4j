# LH01: `label` is followed by an action, and its decision has no ladder or trust

- **Lens:** Human oversight (off until asked for)
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.6.0

A decision with a trust block (or a ladder) says how much freedom the agent has and how it earns more. Without either, whatever follows the decision runs on the agent's word alone.

Why it matters: The agent's choice leads to something being written or sent, and nothing in the script says how the agent earned the right to do that without a person.

What to do: Give the decision a trust block that starts at watch, so a person sees every choice until the agent has a record.

This rule belongs to an optional lens, off until you turn it on (--lens +oversight).

## When it fires

`kind is decide and decideLacksLadder is true and followedByEffect is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LH01 = off` in `review.properties` turns the rule off, and `LH01.severity = low` changes how loud it is.
