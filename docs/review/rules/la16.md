# LA16: A person will run output written from untrusted text

- **Lens:** Security
- **Severity:** varies
- **From:** audit

Output written from untrusted text is meant to be run by a person. Show it for review, never run it automatically.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA16 = off` in `review.properties` turns the rule off, and `LA16.severity = low` changes how loud it is.
