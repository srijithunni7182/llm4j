# LC02: `label` repeats with nothing bounding the conversation, so each round re-sends everything said so far

- **Lens:** Cost and performance
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.1.0

Measured against real providers while building this review: a loop of three rounds cost about twice what three independent calls cost, because round three carries rounds one and two. The shared transcript stops growing only where an agent sets memory { max_tokens } or has a context block. Bounding the loop with max limits the number of rounds; this rule is about what each round costs.

Why it matters: Loom keeps one transcript of every task and answer in the run and puts all of it in front of the next agent. In a loop or for each it grows each round, so the cost of the rounds is not linear: ten rounds cost far more than ten times one.

What to do: Bound the transcript: give the agent memory { max_tokens: ... } or a context block.

## When it fires

`kind is delegate and (inLoop is true or inForEach is true) and agent.hasContext is false and agent.hasMemoryLimit is false`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LC02 = off` in `review.properties` turns the rule off, and `LC02.severity = low` changes how loud it is.
