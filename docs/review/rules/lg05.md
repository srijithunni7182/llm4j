# LG05: Agent `name` uses a prompt file that is not versioned, though other agents' are

- **Lens:** Model governance (off until asked for)
- **Severity:** info
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.6.0

Some agents of this script keep their prompts as versioned files and this one does not. If the project versions prompts, do it for all of them.

Why it matters: Versioned prompt files (prompts/x/v2.md) can be pinned and rolled back. An agent whose prompt is not versioned changes with the file.

What to do: Move its prompt to prompts/<id>/v1.md so it can be pinned.

This rule belongs to an optional lens, off until you turn it on (--lens +governance).

## When it fires

`unversionedAmongVersioned is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LG05 = off` in `review.properties` turns the rule off, and `LG05.severity = low` changes how loud it is.
