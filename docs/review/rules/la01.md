# LA01: One agent has the lethal trifecta

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An agent that reads untrusted content, reaches private data and can send or act can be talked into leaking or acting. Remove one of the three legs, or put a person's approval in front of what it sends.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA01 = off` in `review.properties` turns the rule off, and `LA01.severity = low` changes how loud it is.
