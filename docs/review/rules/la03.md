# LA03: No run budget

- **Lens:** Security
- **Severity:** varies
- **From:** audit

Nothing caps what one run may spend. Add a run budget at the top of the script.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA03 = off` in `review.properties` turns the rule off, and `LA03.severity = low` changes how loud it is.
