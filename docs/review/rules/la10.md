# LA10: A decision that may reach act automatically

- **Lens:** Security
- **Severity:** varies
- **From:** audit

Autonomy to act is granted without a person. Require approval to move up, or keep the ceiling below act.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA10 = off` in `review.properties` turns the rule off, and `LA10.severity = low` changes how loud it is.
