# LA14: A tool the audit cannot see into

- **Lens:** Security
- **Severity:** varies
- **From:** audit

Opaque Java or host tools are assumed to read untrusted content, reach private data and act. Declare what they reach with Name.reach.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA14 = off` in `review.properties` turns the rule off, and `LA14.severity = low` changes how loud it is.
