# LA12: A file tool that may overwrite

- **Lens:** Security
- **Severity:** varies
- **From:** audit

A file tool can overwrite existing files. Use a mode that cannot, or a folder that is only for output.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA12 = off` in `review.properties` turns the rule off, and `LA12.severity = low` changes how loud it is.
