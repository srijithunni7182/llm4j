# LA27: An exposed workflow has no spend cap

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An expose with neither a budget of its own nor a run budget leaves the cost to whoever can call it. Add a budget.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA27 = off` in `review.properties` turns the rule off, and `LA27.severity = low` changes how loud it is.
