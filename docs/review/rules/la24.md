# LA24: A workflow takes input from outside

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An expose block lets other agents call a workflow. Everything it reaches counts as reading untrusted content, so the lethal trifecta rule can fire. Keep those agents away from private data and from tools that send or act.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA24 = off` in `review.properties` turns the rule off, and `LA24.severity = low` changes how loud it is.
