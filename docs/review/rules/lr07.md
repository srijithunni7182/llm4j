# LR07: `label` can write or send inside a loop with nobody approving it

- **Lens:** Reliability
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.2.0

Why it matters: A loop or for each repeats the effect, so one wrong decision is made again for every round or item before anyone looks.

What to do: Put approve: on the tool, or move the effect after the loop and do it once.

## When it fires

`kind is delegate and agent.hasEffects is true and agent.approveAll is false and number of agent.approve is 0 and (inLoop is true or inForEach is true)`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LR07 = off` in `review.properties` turns the rule off, and `LR07.severity = low` changes how loud it is.
