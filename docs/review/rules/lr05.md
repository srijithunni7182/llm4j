# LR05: `label` branches on a field of an answer that has no output_schema

- **Lens:** Reliability
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.2.0

A condition such as r.score < 5 assumes the answer has a score. Only an output_schema makes the model produce one and lets the runtime check it. This rule looks at conditions that read a field of a variable that is bound only by agents with no output_schema.

Why it matters: Without an output_schema the model's answer is free text, so the field the condition reads may be missing or spelt differently, and the branch silently goes the wrong way.

What to do: Give the agent an output_schema that has the field the condition reads.

## When it fires

`kind is one of [alt, loop] and readsFreeText is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LR05 = off` in `review.properties` turns the rule off, and `LR05.severity = low` changes how loud it is.
