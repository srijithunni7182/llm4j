# LM01: Agent `name` is defined but never used

- **Lens:** Maintainability (off until asked for)
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.0.0

Why it matters: An agent nothing uses still has to be read, kept in step with its prompt, and reviewed for what its tools can reach.

What to do: Delete the agent, or use it.

This rule belongs to an optional lens, off until you turn it on (--lens +maintainability).

## When it fires

`referenced is false`

## Fix

`weave review --fix` applies: Delete the unused agent.

## Options

`weave review --assist` offers these, and you choose and give the values.

- **delete**: Delete the agent. The agent's definition is removed. Check first that no other file, such as a test or a Fabric attribute, names it.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LM01 = off` in `review.properties` turns the rule off, and `LM01.severity = low` changes how loud it is.
