# LY02: Agent `name` only warns about personal data but can write or send

- **Lens:** Privacy and compliance
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.0.0

Why it matters: A warning is written to a log and nothing stops the data. An agent that can write or send can pass personal data on.

What to do: Change the guard to pii: mask (or block) so personal data is removed before it reaches the model or a tool.

OWASP LLM Top 10: LLM02

## When it fires

`guardPii is warn and hasEffects is true`

## Fix

`weave review --fix` applies: Mask personal data instead of only warning.

## Options

`weave review --assist` offers these, and you choose and give the values.

- **mask**: Mask personal data. Personal data is replaced by a placeholder before the model or a tool sees it. The agent can no longer use the real value, for example to address an email.
- **block**: Block the call when personal data is present. A request that contains personal data is stopped. Safest, and the most disruptive if the data is expected.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LY02 = off` in `review.properties` turns the rule off, and `LY02.severity = low` changes how loud it is.
