# LO04: `label` may turn more often than a run is allowed to before it is reported as looping

- **Lens:** Observability
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.5.0

Why it matters: Fabric reports a loop that turns more than the loop-incident threshold (20 unless data.loop.incident says otherwise). A bound above it means a normal run can already be reported as an incident.

What to do: Lower the bound, or raise data.loop.incident (and the threshold in the rules file) and say why.

## When it fires

`kind is loop and loopMax > the setting data.loop.incident`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LO04 = off` in `review.properties` turns the rule off, and `LO04.severity = low` changes how loud it is.
