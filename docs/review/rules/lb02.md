# LB02: One run can cause too many effects

- **Lens:** Blast radius (off until asked for)
- **Severity:** medium
- **From:** posture

From the tools its agents hold, tool rounds, retries and repeats, a workflow can cause at most so many sends and writes in one run. When that is more than blast.max-effects (default 25), or has no bound, one bad run can do a lot. What to do: cap the calls with a budget, bound the loops, or split the workflow.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LB02 = off` in `review.properties` turns the rule off, and `LB02.severity = low` changes how loud it is.
