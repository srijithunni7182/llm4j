# LH05: Agent `name` asks a person part-way through its work, in a workflow nobody is watching

- **Lens:** Human oversight
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 6.2.0

Fires when an agent's approve: covers a tool whose effect is changes and the script has a schedule, so no person is working with the agent. A workflow started by hand with weave run, or by a host application, counts as interactive and is not flagged. "Nobody watching" is read from the script, never guessed from prompts.

Why it matters: The run stops in the middle of the agent's reasoning and holds its whole conversation until someone answers, possibly hours later, from a phone. The person sees one tool call without the job it belongs to.

What to do: Let the agent propose, then approve once at the edge: use Tool(...) approve, run Task(...) approve, or a decide. In an interactive assistant, an approval inside the loop is fine.

## When it fires

`asksMidWorkUnattended is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LH05 = off` in `review.properties` turns the rule off, and `LH05.severity = low` changes how loud it is.
