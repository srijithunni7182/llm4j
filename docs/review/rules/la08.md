# LA08: Content fetched from the network

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An MCP server, spec, skill or import is fetched from the network, so what runs depends on something outside the repository.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA08 = off` in `review.properties` turns the rule off, and `LA08.severity = low` changes how loud it is.
