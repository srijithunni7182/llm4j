# LG04: Agent `name` acts on `model.id`, an alias that can change without a commit

- **Lens:** Model governance (off until asked for)
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.0.0

Why it matters: A floating alias such as -latest points at a different model when the vendor moves it, so what the agent does can change with no change to the repository.

What to do: Pin the exact model version for an agent that writes or sends.

This rule belongs to an optional lens, off until you turn it on (--lens +governance).

## When it fires

`model.floatingAlias is true and hasEffects is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LG04 = off` in `review.properties` turns the rule off, and `LG04.severity = low` changes how loud it is.
