# LP03: Agent `name`'s prompt is about `promptTokens` tokens

- **Lens:** Prompts
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.2.0

The limit is data.prompt.max-tokens in review.properties (default 2000). Tokens are counted the way the run-time guard counts them.

Why it matters: A very long prompt is paid for on every call, and the instructions that matter are easier to lose in it.

What to do: Cut the prompt down, or move reference text into a knowledge base the agent can search.

## When it fires

`promptTokens > the setting data.prompt.max-tokens`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LP03 = off` in `review.properties` turns the rule off, and `LP03.severity = low` changes how loud it is.
