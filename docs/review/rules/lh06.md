# LH06: `label` asks a person to approve a tool that only reads

- **Lens:** Human oversight
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 6.2.0

The step form of LH02. A use step with approve on a tool whose effect is none or reads asks a person to confirm something that cannot do harm. Approval is for steps that send or change something.

Why it matters: When people are asked to approve things that cannot do harm, they learn to click yes without reading, and the approvals that matter get the same click.

What to do: Remove approve from this step, or declare the tool's effect as changes (effect: changes) if it does change something.

## When it fires

`approvesLowEffectTool is true`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LH06 = off` in `review.properties` turns the rule off, and `LH06.severity = low` changes how loud it is.
