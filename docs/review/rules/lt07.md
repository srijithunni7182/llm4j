# LT07: A test names something the script no longer has

- **Lens:** Testability (off until asked for)
- **Severity:** medium
- **From:** testability

A test that scripts or checks an agent, classifier, tool or task that is not in the script is stale: it passes or fails for the wrong reason. What to do: rename it in the test, or delete the case.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LT07 = off` in `review.properties` turns the rule off, and `LT07.severity = low` changes how loud it is.
