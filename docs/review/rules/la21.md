# LA21: The transcript carries untrusted text to a later agent

- **Lens:** Security
- **Severity:** varies
- **From:** audit

An agent that receives the whole transcript after an agent that reads untrusted content has run is exposed to what it read. Give it transcript: none or own, or split the work.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA21 = off` in `review.properties` turns the rule off, and `LA21.severity = low` changes how loud it is.
