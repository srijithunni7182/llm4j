# LV03: A result is set but never used

- **Lens:** Validity
- **Severity:** varies
- **From:** validator

The step's answer is bound to a name that nothing reads, which usually means the answer is thrown away or a later step was forgotten. An error from weave check is a high finding and a warning a low one. What to do: Use the result (in a note, a condition or a later step) or remove the binding.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LV03 = off` in `review.properties` turns the rule off, and `LV03.severity = low` changes how loud it is.
