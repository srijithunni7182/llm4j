# LP08: Agent `agent.name` does not see the run's earlier exchanges, and this task passes it nothing from them

- **Lens:** Prompts
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 6.2.0

memory with transcript: none gives an agent no transcript and transcript: own only its own earlier exchanges, so its task is its whole briefing. This rule is quiet when the task passes at least one variable, because the author clearly passed what was needed; under substitution: legacy a bare variable name counts too.

Why it matters: The agent has been told to leave the transcript (transcript: none or own), so everything it needs must be in its task. A task with no variable in it carries nothing from the run.

What to do: Write a variable into the task (a name in curly braces) so it carries what the agent needs, or give the agent transcript: all.

## When it fires

`passesNoVariable is true and agent.transcript is not all`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LP08 = off` in `review.properties` turns the rule off, and `LP08.severity = low` changes how loud it is.
