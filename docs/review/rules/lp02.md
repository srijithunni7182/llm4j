# LP02: Agent `name` decides a branch but its prompt does not say what shape the answer must have

- **Lens:** Prompts
- **Severity:** medium
- **From:** the core rule pack
- **Applies to:** each agent
- **Since:** core 1.5.0
- **Heuristic:** yes, it guesses from names or wording, so it runs only with `heuristics = on` or when named in `review.properties`.

This rule guesses from the wording of the prompt, so it runs only with heuristics on. It looks for phrases such as respond with, one of the following, JSON, yes or no.

Why it matters: A condition compares the agent's answer with a word. If the prompt does not say which words are allowed, "Yes." and "yes" and "I think so" all appear.

What to do: Tell the agent to answer with exactly one of the allowed words, or give it an output_schema.

This rule guesses from names or text, so it runs only when heuristics are on or the rule is named in review.properties.

## When it fires

`feedsBranch is true and hasSchema is false and promptStatesFormat is false`

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LP02 = off` in `review.properties` turns the rule off, and `LP02.severity = low` changes how loud it is.
