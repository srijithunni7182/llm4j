# LC03: `label` sends the same work to several agents and one of them runs on one of your most expensive models

- **Lens:** Cost and performance
- **Severity:** low
- **From:** the core rule pack
- **Applies to:** each step
- **Since:** core 1.5.0

Why it matters: Fanning out multiplies the cost of every call. On a top-tier model that is the part of a run most worth looking at.

What to do: Use a cheaper model for the fanned-out agents, or fan out to fewer of them.

## When it fires

`kind is one of [broadcast, parallel] and number of fanOutAgents >= 2 and some of fanOutAgents where (model.id is one of the setting data.top-models)`

Not evaluated unless the project declares: `data.top-models` in `review.properties`.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LC03 = off` in `review.properties` turns the rule off, and `LC03.severity = low` changes how loud it is.
