# LA02: Effects with no approval

- **Lens:** Security
- **Severity:** varies
- **From:** audit

A tool that sends, writes or runs something is called with no person's yes. Name the tool in the agent's approve: list.

## Handle it without editing code

`weave review --accept FINGERPRINT --reason "why"` records that the finding is fine. `LA02 = off` in `review.properties` turns the rule off, and `LA02.severity = low` changes how loud it is.
