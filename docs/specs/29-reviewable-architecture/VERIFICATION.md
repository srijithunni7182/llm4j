## 7. Results


### 29 as built (2026-11-04)

**29a, the probes.** Nine probes, P9 to P17, one folder each (`extractor-isolation`, `large-schema-with-tools`, `exit-check`, `approval-placement`, `untested-guard`, `tool-effects`, `handoff-check`, `long-loop-progress`, `route-allowlist`), each with `python/probe.py` (LangGraph, LangChain, ADK on fake models, plus a search of the installed packages through `_common/fakes.py`), `loom/` scripts and a `run.sh`, and stored `results/`. `probes/run-frameworks.sh` reruns them. Findings that went against what I expected, recorded in the README as found: in ADK 2.13.0 `include_contents='none'` removed the user's message but the previous agent's output still arrived in a `SequentialAgent` (an `AgentTool` did not); LangGraph's `interrupt()` restarted the node after the answer, so the text sent was not the text shown; LangGraph's conditional edge with a target list refused an out-of-list route at run time; LangChain's tool list and ADK's `sub_agents` are allow-lists by construction. **Not run:** ADK's Model Armor integration (needs a Google Cloud project) and ADK's context compaction; the README says so.

**29b, the page.** `docs/REVIEWABLE_ARCHITECTURE.md`: the claim in the owner's words, why a language makes it possible (the small workflow beside its generated graph), the thirteen mistakes each with a script, the output `weave` prints now (generated by `ReviewableArchitectureDocsTest`, rewrite with `-Dregenerate.architecture.page=true`) and a fixed script that the test requires to pass `weave check` (and, where it names a rule, to be clean of that rule), "what is not enforced", where to go next. The test also checks that every rule id exists, every probe link resolves, each of P9 to P17 is linked, and a framework is named only in a line that links a probe.

**29c, the stack pages.** `WHY_LLM4J.md` gained a section with a row per mistake and a line at the top (`WhyLlm4jLinksProbesTest`); the root README, wiki Home, `docs/README.md`, `THE_STACK.md`, `DEVELOPER_GUIDE.md`, the tutorial README, `llms.txt`, the VS Code README (and its CHANGELOG), the workflow-guide skill and the release notes carry the claim; `WHY_LOOM.md` gained only its "see also" line (D31).

**29d, the article.** `docs/articles/REVIEWABLE_ARCHITECTURE_ARTICLE.md`, listed in the docs index; tests check it links the page, links the same probe sections, names no rule the page does not and names a framework only beside a probe link. It restates the page; it adds no claim.
