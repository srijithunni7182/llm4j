# eval4j-report

**Status: specification only.** No code yet. The specs live in [`spec/`](spec/00-OVERVIEW.md).

`eval4j-report` is an add-on to [`eval4j`](../eval4j/README.md). `eval4j` runs the evaluations and exports each run in a documented **run bundle** (JSON and JSON Lines). `eval4j-report` reads run bundles and builds the dashboard: an interactive HTML report, a static edition for locked-down viewers such as Jenkins, a run comparison, and CI-ready summaries.

Start with [`spec/00-OVERVIEW.md`](spec/00-OVERVIEW.md).
