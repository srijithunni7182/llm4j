## Meet the Loom Guide

Your coding agent builds the workflow. The **Loom Guide** walks you through it: it explains each stage before it happens (why a golden dataset comes before the script, what an approval protects, what the evaluation measured), opens the graph, the review and the report at the right moment, and asks you for the decisions that are yours. It never edits a file, so it is free to answer your questions while the agent works.

The Guide runs on the assistant you already pay for: pick **llm4j-guide** in Copilot Chat's agent list, or run it in Claude Code. No new key, no new bill.

This step writes `.github/agents/llm4j-guide.agent.md` (Copilot), `.claude/agents/llm4j-guide.md` (Claude Code) and the `llm4j-guide` entry in `.mcp.json`. A file you changed is left alone.

[Set Up the Guide](command:loom.guide.setUp)

Then open it any time with **Loom: Open the Guide**, or click the Guide's note count in the status bar.
