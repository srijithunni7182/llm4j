## Let your coding agent do the typing

You do not need to learn `.loom` syntax, and you do not need to put a model API key into this extension. The coding agent you already use (Claude Code, GitHub Copilot, Cursor or Codex) can design, build, test and deploy a complete workflow when it has Loom's four skills.

This step copies the skills into `.agents/skills`, `.claude/skills` and `.github/skills`, and adds a short Loom section to `AGENTS.md`. Anything you wrote in `AGENTS.md` stays as it is.

[Set Up Coding Agent](command:loom.installSkill)

When it finishes, your agent chat opens with a starter prompt already typed in.
